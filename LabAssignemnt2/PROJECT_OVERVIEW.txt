                    MULTI-ROBOT BOOK SORTING SYSTEM
                        Lab Assignment 2 - Final Version
                         Industrial Robotics Course
════════════════════════════════════════════════════════════════════════════════

PROJECT DESCRIPTION:
This project implements an automated book sorting system using 4 industrial robots
that collaborate to sort and stack 6 colored books (2 red, 2 green, 2 blue) in a
shared workspace with comprehensive safety features.

════════════════════════════════════════════════════════════════════════════════
HOW TO RUN THE SYSTEM:
════════════════════════════════════════════════════════════════════════════════

1. Open MATLAB
2. Navigate to the LabAssignment2 folder
3. Run: main.m
4. The GUI will launch automatically
5. Click "▶ START BOOK DEMO" to run the complete demo

════════════════════════════════════════════════════════════════════════════════
ROBOT SYSTEM OVERVIEW:
════════════════════════════════════════════════════════════════════════════════

Four Robots Operating in Shared Workspace:

1. LinearUR3 (7-DOF with linear rail)
   - Role: Sorts all 6 books from initial pile into 3 color-coded piles
   - Books processed: All 6 books (2 red, 2 green, 2 blue)
   - Location: Center workspace

2. YaskawaGP4/MotomanGP4 (6-DOF)
   - Role: Picks red books and stacks them at final location
   - Books processed: 2 red books
   - Location: Right side of workspace

3. KukaKr3R540 (6-DOF)
   - Role: Picks green books and stacks them at final location
   - Books processed: 2 green books
   - Location: Left-front of workspace

4. AuboI5 (6-DOF Collaborative Robot)
   - Role: Picks blue books and stacks them at final location
   - Books processed: 2 blue books
   - Location: Right-front of workspace

════════════════════════════════════════════════════════════════════════════════
DEMO SEQUENCE (Sequential Operation):
════════════════════════════════════════════════════════════════════════════════

The demo runs automatically in 4 phases when you click "START BOOK DEMO":

PHASE 1: UR3 SORTING (First Robot - Books Start Here!)
   - UR3 picks all 6 books from initial stacked piles at X=-1.75
   - Sorts them by color into 3 separate piles:
     * Red books → Right pile (Y=0.525)
     * Green books → Left pile (Y=-0.525)
     * Blue books → Center pile (Y=0)
   - Creates organized workspace for other robots

PHASE 2: MOTOMAN RED BOOKS
   - Picks 2 red books from UR3's sorted pile
   - Stacks them at final location (Y=1.05)

PHASE 3: KUKA GREEN BOOKS
   - Picks 2 green books from UR3's sorted pile
   - Stacks them at final location (Y=-1.05)

PHASE 4: AUBO BLUE BOOKS
   - Picks 2 blue books from UR3's sorted pile
   - Stacks them at final location (X=0.85, Y=0)

All robots operate sequentially (one at a time) to avoid collisions.
The system ensures books are passed between robots via sorted piles.

════════════════════════════════════════════════════════════════════════════════
MANUAL CONTROL vs DEMO MODE:
════════════════════════════════════════════════════════════════════════════════

The system correctly separates manual control from demo mode:

MANUAL CONTROL MODE (Default):
   - All joint and Cartesian controls are ENABLED
   - You can select any robot and jog it manually
   - E-Stop blocks movement when active
   - Sensor triggers block movement when breached

DEMO MODE (When "START BOOK DEMO" is running):
   - All manual controls are DISABLED automatically
   - Only E-Stop and sensor buttons remain active
   - Demo runs automatically through all 4 phases
   - Cannot control robots manually during demo

You CANNOT do manual control and demo at the same time.
This is by design to prevent interference with automated operations.

TESTING THE SYSTEM:
════════════════════════════════════════════════════════════════════════════════

TEST 1: Complete Demo
   1. Run main.m
   2. Click "START BOOK DEMO"
   3. Observe all 4 phases execute sequentially
   4. Verify books are sorted and stacked correctly

TEST 2: E-Stop During Demo
   1. Start the demo
   2. Press "EMERGENCY STOP" button during operation
   3. Verify system halts immediately
   4. Press "RESUME OPERATIONS"
   5. Verify demo continues from where it stopped

TEST 3: Sensor Simulation
   1. Click "TRIGGER SENSOR"
   2. Try to move robot (should be blocked)
   3. Click "CLEAR SENSOR"
   4. Verify movement is permitted again

TEST 4: Collision Detection
   1. Ensure "COLLISION DETECTION: ON"
   2. Run demo and observe status updates
   3. Click toggle to turn OFF
   4. Run demo again (collision checking disabled)
   5. Click toggle to turn back ON

TEST 5: Manual Control
   1. Select a robot from dropdown
   2. Use joint jog buttons (J1-J7)
   3. Use Cartesian controls (X, Y, Z)
   4. Move robot to home position
   5. Verify E-Stop blocks manual movements

TEST 6: Reset System
   1. Run partial demo
   2. Click "RESET SYSTEM"
   3. Verify all robots return home
   4. Verify books respawn at original locations
   5. Run demo again successfully
